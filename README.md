# CodeQadam — БӨОЖ білім беру сайты

**Тақырыбы:** Python бағдарламалау негіздері.  
**Мақсаты:** оқушыларға Python тілінің бастапқы ұғымдарын түсінікті мысалдармен үйрету.  
**Мақсатты аудитория:** бағдарламалауды жаңадан үйреніп жүрген оқушылар.  
**Құрылымы:** басты бет, үш теориялық сабақ (print(), айнымалылар, шартты оператор), үш практикалық тапсырма, бес сұрақтық интерактивті тест және кері байланыс формасы.

## Іске қосу
`index.html` файлын браузерде ашыңыз. Қосымша сервер немесе тәуелділік қажет емес. Google Fonts қосылымы болмаса, жүйелік sans-serif қарпі пайдаланылады.

## Қолданылған ЖИ құралы
OpenAI ChatGPT — тақырып, қазақ тіліндегі оқу мазмұны, код мысалдары, тапсырмалар, тест сұрақтары және бастапқы интерфейс құрылымын дайындауға пайдаланылды. Материалды тапсырар алдында оқушының өзі қарап, тексеруі керек.

## Тапсыруға арналған сипаттама
CodeQadam — Python-ды бастапқы деңгейде үйрететін бір беттік білім беру сайты. Жоғарғы навигация бөлімдерге апарады; шағын экранда мәзір жиналады. Тест жауапты автоматты тексереді, практикалық тапсырмаларда ишара ашылады, кері байланыс формасы жазылған пікірді экранда көрсетеді.

## Қорытынды
ЖИ құралдары сайт құрылымын, түсіндірмелер мен тапсырмалардың алғашқы нұсқасын жылдам дайындауға көмектесті. Нәтижесінде теория, практика және білімді тексеру бір ортада біріктірілді. Кері байланыс демо-нұсқада серверге жіберілмейді. Скриншот дәлелдерін тапсыру үшін сайтты браузерде ашып, әр бөлімнің көрінісін түсіріңіз.
