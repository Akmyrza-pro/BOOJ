01 — негіздері

Үш сабақ. Бір жаңа дағды.

Әр тақырыпта қысқа түсіндірме мен өзің тексеріп көруге болатын код үлгісі бар.

👋5 минут

Алғашқы бағдарлама

print() командасы экранға мәтін немесе есептеу нәтижесін шығарады. Мәтін тырнақшаға жазылады.

# Экранға хабар шығару
print("Сәлем, әлем!")
print(2 + 3)
# Нәтиже: 5
📦7 минут

Айнымалылар

Айнымалы — деректі сақтайтын атаулы орын. Мәнді = белгісімен тағайындаймыз. Python атауды оқып, мәнін қолданады.

# Аты мен жасын сақтау
name = "Аружан"
age = 16
print(name)
print(age + 1)
🔀8 минут

Шартты оператор

if шартты тексереді. Шарт дұрыс болса бірінші блок, әйтпесе else блогы орындалады. Шегініс блокты белгілейді.

# Жасты тексеру
age = 16
if age >= 16:
  print("Рұқсат")
else:
  print("Әлі ерте")
02 — қолданып көр

Енді сенің кезегің.

Тапсырманы редакторда орында. Көмек керек болса, ишараны аш.

ТАПСЫРМА 01

Сәлемдес!

print() көмегімен өз атыңды және сүйікті пәніңді екі бөлек жолға шығар.

Екі print() командасын қолданып көр: print("Менің атым... ")
ТАПСЫРМА 02

Жасты есепте

birth_year айнымалысына туған жылыңды жазып, ағымдағы жылмен жас мөлшерін есепте.

Мысалы: age = 2026 - birth_year, кейін нәтижені print() арқылы шығар.
ТАПСЫРМА 03

Сан жұп па?

n санын тексер. Егер 2-ге қалдықсыз бөлінсе «Жұп», әйтпесе «Тақ» деп шығар.

n % 2 == 0 шарты санның жұп екенін тексереді. Оны if ішінде қолдан.

Бес сұрақтық шағын тест.

Әр сұраққа бір жауап таңда. Соңында нәтижеңді бірден көресің.

1. Мәтінді экранға шығаратын команда қайсы?

2. Айнымалыға мән қалай беріледі?

3. Шарт жалған болғанда қай сөз қолданылады?

4. 2 + 3 өрнегінің нәтижесі қандай?

5. Python-да шарт блогы қалай белгіленеді?
